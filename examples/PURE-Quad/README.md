# Example: PURE Quad — ExtendedLSC menu config

This is a real, shipping ELSC menu config for **PURE**, a 250+ part quad-customization add-on (a GTA V
recreation of Disney / Black Rock Studios' *PURE*). It's the reference example for what ExtendedLSC enables.

PURE crams **251 parts into 22 GTA mod slots**. This config reorganizes them into a menu that actually makes
sense:

- **Bodies → Body 1…10** — pick a body shell, then customize *that body's* matching **Front Fenders, Rear
  Fenders, Nose Cones, Radiator Scoops, and Seats** (the parts are named per-body in the mod, so each body
  owns its attachments).
- **Global categories** — Front Bumpers, Engines, Handlebars, Grips, Nerf Bars, Hand Guards, Frame Guards,
  Frames, Swing Arms, A-Arms, Shocks, Sprockets, Brake Kits, NOS.
- Irrelevant default categories are hidden (`_config.json`), every single-slot category auto-offers a
  **None** option, and empty menus don't show.

## Install
Copy the `Vehicles\blazer4\` folder into your `scripts\ExtendedLSC\Vehicles\` folder. Sit on the PURE quad,
open ELSC (**F5**), done. (The folder is named `blazer4` after the model, so it matches automatically.)

> Requires the **PURE vehicle add-on** itself (distributed separately — it's a 600 MB+ DLC, too large for
> this repo). This folder is only the ELSC *menu layout* for it.

## How it was made
Generated by parsing the vehicle's `carcols.meta` (mapping each part's `VMT_*` type → mod slot and its
position → index), then **validated against the live game** by comparing `GET_NUM_VEHICLE_MODS` per slot.
See [docs/CUSTOM-MENUS.md](../../docs/CUSTOM-MENUS.md) and [docs/DISCOVERIES.md](../../docs/DISCOVERIES.md).
